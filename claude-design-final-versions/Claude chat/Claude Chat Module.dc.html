Claude Chat

Claude Chat is the conversational Claude experience for asking questions, drafting, analysing, summarising, translating and creating reusable outputs. This module shows you when to reach for it, how to give it useful context, and how to use it within Sandvik's guidelines.

Claude can accelerate your work, but you remain responsible for what you enter, approve, share and publish. Follow Sandvik policy, protect sensitive information, and review outputs before relying on them.

Getting started

There are three ways to use Claude. They share the same account and history, so you can start on one and continue on another.

01
Web browser

Go to www.claude.ai and sign in. Nothing to install.

02
Desktop app

Download Claude as a desktop app from the internal Company portal.

03
Mobile app

Install the Claude app on your phone for quick access on the move.

What you'll see

The chat

The large area in the middle is where you work. Type a message in the box to start, and the conversation builds up here as you and Claude exchange turns.

Chat history

The left sidebar keeps your past conversations. Start a New chat at any time, and reopen earlier ones from Recents to pick up where you left off.

Choosing a model

Model selection

The control at the bottom of the message box is where you pick the model and how much effort it puts in. Different models suit different tasks.

The Thinking toggle turns on multi-step reasoning, where Claude works through a problem in steps. It is on by default, and the next page explains it.
Multi-step reasoning

With multi-step reasoning, Claude works through a problem in steps before answering, rather than replying the moment you press send. The result is a more considered answer.

It is turned on by default, so you usually don't need to do anything. For harder questions you'll see Claude reason for a moment before it answers.

How it works

A direct answer is a single guess. Multi-step reasoning lets Claude break a problem into parts, work through them, and check itself before replying. It is most useful for analysis, comparisons, planning and anything with several moving parts.

1Claude reads your question and understands what it needs to solve.
2It breaks the problem into smaller parts.
3It works through each part in turn.
4It checks the parts fit together.
5It delivers a clear, well-reasoned answer.

An example

Ask Claude to draft a one-page update and it can plan the work first, then move through it step by step, keeping track of progress inside the conversation.

Example checklist for a one-page project update
Clarify audience
Identify key messages
Draft update · in progress
Check risks and assumptions
Shorten for leadership
You can follow Claude's reasoning as it works, which makes it easier to see how it reached an answer. Treat the result as a draft and check it before you act on it.
Tool capabilities · 1 of 5

Files

Context you attach

Files let Claude work with material you provide, such as a policy draft, report, spreadsheet, meeting notes, or specification. Claude can summarise, compare, extract, rewrite, and answer questions about the content.

Adding a file

Click the + in the composer and choose Add files or photos, or simply drag and drop files straight into the chat.

Common file types include Word documents, PDFs, and PowerPoint presentations.

Long documents
Claude can work with long documents, even hundreds of pages, as long as the material fits within the available context and is organised enough to follow. More context is not always better: large or messy uploads can make it harder for Claude to focus on the right evidence, and can raise the risk of missed details or confident mistakes.
For large files
Tell Claude exactly what to look for, which sections matter most, and what it should ignore.
Spreadsheets and datasets
Treat Claude as a reasoning and explanation assistant rather than a dedicated data-analysis system. It can summarise, inspect, and explain patterns, but important calculations, formulas, row counts, and conclusions need to be checked against the original file or a proper analysis tool.
Good habit: more context is not always better. For data, verify the important figures against the source.
Tool capabilities · 2 of 5

Connectors and tool access

Context Claude retrieves

Connectors let Claude connect to approved apps and services. A connector may let Claude retrieve data, search a system, or in some cases take actions in that service.

The idea is that connectors bring extra context into Claude Chat without you copying everything by hand. Claude uses the connected service through your login and permissions. If you cannot access a file, channel, record, or repository through your own account, the connector cannot give Claude access to it either.

Adding and managing connectors

Add a connector from the Customize tab: open Customize > Connectors, pick a connector, and connect it.

Each connector lists its tool permissions, so you can see exactly what tools it provides and choose when Claude is allowed to use them. You only see tools your organisation has given you access to.

Once connected, the connector appears in the + menu under Connectors, ready to switch on for a chat. Open Tool access there to review its tools at any time.

About MCP: connectors run on MCP (Model Context Protocol), the standard that lets tools plug into Claude. In time there will be options to connect your own Sandvik systems this way.
Approved connectors today
Microsoft 365 Active
›Find or summarise documents from SharePoint.
›Get the last week's meeting transcripts and summarise action points.
›Find available time slots for a meeting.
GitHub Active
›Understand a codebase and explain how it works.
›Summarise recent changes or a pull request.
›Find where something is implemented across a repository.
There aren't many Sandvik approved connectors yet, but connectors are an essential way of making data available to Claude, and more are on the way. A future shared site will list the approved connectors (MCPs) as they become available.
Good habits
›Understand what Claude is trying to access or do through connectors.
›Prefer narrow access and specific prompts.
›Pause to think before you accept an action that sends, creates, updates, or deletes anything in another system.
›Watch for prompt injection in retrieved content, especially emails, documents, web pages, tickets, or repositories.
Tool capabilities · 3 of 5

Projects

Context you organise

Projects are focused Claude workspaces with their own chats, project knowledge, and project instructions. Use a project when you will return to the same topic or set of approved materials over time.

Open Projects from the left side panel, then create a new project or pick an existing one.

Creating a project

Name the project and describe what you are trying to achieve, then set Visibility before you create it.

Choose Private. The Sandvik option makes the project, its knowledge and its chats visible to the whole Sandvik organisation.

Once it is private, share it individually with the specific people who should have access.

Always set visibility to Private, otherwise everyone at Sandvik will have access to your project.

Once created, each project looks like this.

What a project gives you
Instructions
Always on for every chat in the project. Write the learnings, working method, or a description of the task or project you are on, and Claude applies it each time without you repeating yourself.
Files
Project knowledge stays attached as context the whole time, so every chat can draw on it. Add it once instead of re-uploading the same material in each conversation.
Collaboration
A project is shared. People with access work in the same instructions and files, so a team builds on one shared context rather than scattered private chats.
Shared chats
Your chats stay private until you share them. Once you share a chat you ran in the project, everyone with access to the project can reuse that chat as context for their own work.
Before using or sharing a project, check
Who can access the project?
Do those people have the right to see the knowledge and chat context?
Are the project instructions still accurate?
Should outdated files be removed?
Tool capabilities · 4 of 5

Skills

Reusable instructions and resources

Skills are reusable packages of instructions and resources that Claude loads when relevant to a task. A skill can hold things like templates, reference guidelines, and scripts, so Claude performs specialised work the same way every time.

Find your skills under Customize > Skills. They come in two kinds:

Personal skills
Skills you create or add for your own use, such as the built-in skill-creator.
Organization skills
Skills your admin makes available to everyone. In this example there are two for creating presentations, sandvik-pptx and sandvik-html.
How a skill gets used
Applied automatically

Claude recognises when a skill fits the task and applies it on its own. Ask for a Sandvik presentation and Claude picks up the presentation skill without you naming it.

Called directly

You can also invoke a skill on purpose by typing / followed by its name in the message box.

Creating a skill

To create a skill in Claude, write /skill-creator. Claude builds a skill that you can decide to save for future use. To share a skill with other people, follow the guidance in the AI Champion Journey.

As with connectors, a future shared site will list the Sandvik-approved skills, so teams can reuse the same trusted skills rather than rebuilding their own.
Good habits
›Check whether a skill is relevant before relying on it.
›Remember that a skill improves the workflow, but it does not make the output automatically correct or approved.

Artifacts

Outputs you reuse

Artifacts are standalone outputs Claude produces alongside the conversation. They are useful when the result is something you will inspect, edit, download, reuse, or share.

An artifact can be
A document A diagram A visualisation A code snippet A simple web page An interactive component
Example

For a steering-group update, an artifact might be a milestone timeline, a process flow diagram, or a risk heatmap that you can refine and drop into your report.

Claude can also build a full interactive dashboard from data you provide. A short prompt like this one is enough to get started:

A polished artifact looks convincing, so the real test is the data behind it. Before you rely on or share figures like these, make sure you understand exactly where each number came from and can verify it against the source.
Sharing artifacts

Artifacts can be shared with other people. You can publish one and send a link, so colleagues can view it without opening your chat. Because sharing makes the artifact visible beyond you, check what it exposes and confirm it is cleared before you send it on.

Good habit: treat every artifact as a draft until it has been checked against the source and Sandvik policy, and confirm it is cleared before you share or publish it.

Sandvik rules & governance

What's allowed, what needs care, and where to go for help and discussion.

Approved
Approved use
Claude Chat is a Sandvik-approved tool for the conversational work described in this module: thinking, drafting, analysing, summarising and creating reusable outputs.
Use care
Data classification (SICS)
Claude is approved for data classified i1–i3 under the Sandvik Information Classification System: i1 Public, i2 Restricted (the default for most documents) and i3 Confidential. Do not use it with i4 Secret information. You are responsible for classifying your information correctly. Never upload passwords, secret keys or other credentials. Work efficiently and manage usage

At Sandvik, Claude usage is direct, consumption-based. There are no five-hour session or weekly limits. Every conversation consumes tokens, billed pay-as-you-go to your cost center, so working efficiently keeps both setup time and cost down.

Costs for heavy, context-rich work can rise quickly, so keep an eye on your usage in Settings > Usage and keep conversations scoped.

For lighter work, reach for Copilot
Microsoft Copilot is not consumption-based, so you can use it freely without adding cost to your cost center. For simpler, everyday tasks, use Copilot and save Claude for the more complex work where it earns its cost.
Usage (consumption)

How much you consume over time. Sandvik usage is billed on a pay-as-you-go basis to your cost center, so the more context Claude works with, the more it costs.

Length and context

How much material Claude can work with in one conversation. Longer chats and larger inputs fill the context and raise the token cost of every following message.

What drives token usage

Usage is not just a count of messages. It can be affected by:

›The length of your conversation.
›The size and number of files, project materials, or artifacts Claude uses.
›The model, effort, or thinking settings available to you.
›Tool use, web search, research, connectors, and other context-heavy features.
›Reusing long chats instead of starting a focused new conversation.
›The amount of reasoning required to reach a conclusion, such as creating scripts or understanding images.
Practical habits
Start a new focused chat when the topic changes.
Use projects for approved materials you reference repeatedly instead of re-uploading the same files.
Use project instructions for stable context such as preferred tone, terminology, or output structure.
Use approved skills for recurring workflows, formats, or visualisations where Sandvik allows them.
Reuse and edit an existing artifact instead of regenerating a similar output from scratch.
Turn off web search, research, or connectors when they are not needed for the task.
Choose simpler model, effort, or thinking settings for routine work where available and appropriate.

These practices save setup time and reduce unnecessary context, but they do not remove Sandvik cost controls or the need to review Claude's outputs.

If you need more capacity
›Check your usage in Settings > Usage if available.
›For business work that needs more capacity, request a higher monthly usage or spending limit through the service portal →
›Expect the higher monthly spending limit to require approval from your cost approver.
›Your monthly spending limit should be visible in your Claude account.
Not allowed
Do not move Sandvik work into private accounts or unapproved tools to avoid limits or cost.
