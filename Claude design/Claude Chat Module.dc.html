Claude Chat

Claude Chat is the conversational Claude experience — for asking questions, drafting, analysing, summarising, translating and creating reusable outputs. This module shows you when to reach for it, how to give it useful context, and how to use it within Sandvik's guidelines.

Claude can accelerate your work, but you remain responsible for what you enter, approve, share and publish. Follow Sandvik policy, protect sensitive information, and review outputs before relying on them.

Tool fit

Claude Chat holds the foundational features of Claude. It is not Claude Code, Cowork or Design. Choosing the right product is the first decision.

Use Claude Chat when
—You are thinking through a problem and want an interactive thought partner.
—You need a first draft, summary, translation, comparison, checklist or structured analysis.
—You want to upload or paste selected context and ask questions about it.
—You want text or an artifact you can inspect, edit and reuse.
—You want Claude to use approved tools or connectors inside a controlled conversation.
Reach for another product when
—The deliverable spans many files, browser steps or desktop actions → Claude Cowork.
—You need to read and change a codebase, run tests or use dev tools → Claude Code.
—The main output is visual exploration, prototypes, slides or design → Claude Design.

Tool-assisted flow

Claude can use approved tools to bring new context back into the chat — then adapt to what it finds.

1You ask Claude for a daily summary from your emails.
2Claude identifies that inbox context is needed.
3It uses a Sandvik-approved email connector, via your permissions.
4The connector returns email contents.
5Claude drafts the summary from that context.
6You review sources, assumptions and policy before sharing or acting.
You remain responsible for deciding whether the tool should be used, whether the context is appropriate, and whether the output is reliable enough to act on.
Tool capabilities

The context stack

Each feature changes what Claude can see, retrieve, reuse or produce. Use them deliberately.

Files
Context you attach

Work with material you provide — reports, spreadsheets, notes, specs. Claude can summarise, compare, extract, rewrite and answer questions about the content.

Watch: more context isn't always better. For data, verify calculations against the source.
Connectors
Context Claude retrieves

Approved apps and services bring extra context into a chat. Claude works through your login and permissions — M365 (pending approval), HubSpot, GitHub.

Watch: prefer narrow access; pause before any write action; watch for prompt injection in retrieved content.
Projects
Context you organise

Focused workspaces with their own chats, project knowledge and instructions. Upload approved materials once; set stable tone and terminology.

Check: who can access it, whether they may see the knowledge, and that instructions are current.
Skills
Reusable instructions

Packages of instructions and resources Claude loads when relevant — standard formats, team methods, recurring workflows. Create one with /skill-creator.

Remember: a skill improves the workflow — it doesn't make the output automatically correct or approved.
Artifacts
Outputs you reuse

Standalone outputs — documents, diagrams, visualisations, code snippets, simple web pages, interactive components. Useful when the result is something you'll inspect, edit, download, reuse or share. For a steering-group update, an artifact might be a milestone timeline, a process flow diagram, or a risk heatmap.

Treat as a draft until checked against the source and Sandvik policy.

Common risks & mistakes

Most problems fall into five groups. For each, there's a simple habit that avoids it.

Data & confidentiality

Pasting information you're not cleared to use, giving connectors more access than needed, or trusting retrieved content that carries hidden instructions (prompt injection).

Do instead — enter only authorised material, prefer narrow access, and scan retrieved content before acting on it.
Wrong tool choice

Forcing Claude Chat to do work that belongs in Claude Code, Cowork or Design — and getting weaker results.

Do instead — match the product to the work before you start.
Over-trusting output

Treating a fluent answer as verified fact, trusting spreadsheet maths, or letting long, messy chats hide missed details.

Do instead — treat answers as drafts, verify important figures, and start a fresh focused chat when the topic changes.
Sharing & publishing

Sharing artifacts or downloads without checking what they expose or validating the information first.

Do instead — run the review checklist before anything leaves your screen.
Cost & usage

Long unfocused conversations, re-uploading the same files instead of using a project, or moving work to private accounts to dodge limits.

Do instead — scope context, reuse projects and artifacts, and request a higher limit through the proper route.
Across all of these, one rule holds: human users remain accountable for outputs.
