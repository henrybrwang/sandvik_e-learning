Core workflow

Five steps, every time

The same rhythm works whether you're drafting an email or analysing a report. Reuse it on every task.

01
Prepare context
Open a project or new chat. Paste only the source material you're cleared to use.
02
Set boundaries
State the role, format and limits. Say what's confidential and what not to invent.
03
Use the tool
Ask, iterate, refine with follow-ups — not one giant prompt.
04
Review output
Treat every answer as a draft. Verify facts, figures and citations against trusted sources.
05
Share safely
Only paste outputs into approved channels. Remove anything that shouldn't leave Sandvik.
