# Portal Copy: Claude Chat

## Short Description

Learn when to use Claude Chat, how context makes it useful, how agentic or tool-assisted chat differs from built agents, and how to work with files, connectors, projects, skills, artifacts, usage limits, sharing, and output review.

## Long Description

This module prepares Sandvik users to use Claude Chat as a focused tool module within the broader AI Fluency program. It briefly recaps safe AI and prompting basics, then focuses on what is different about Claude Chat: choosing Chat for the right work, giving context and boundaries, understanding built agents versus agentic or tool-assisted chat, using Claude-specific context features responsibly, managing usage and cost, treating artifacts as drafts, verifying outputs, and choosing another Claude or Sandvik-approved tool when it is a better fit.

## Completion Rule

Users must pass the scored quiz with at least 80%. Retakes are unlimited.

## Estimated Time

35-45 minutes.

## Audience

Required for users ordering Claude Chat.

## Prerequisites

None.
