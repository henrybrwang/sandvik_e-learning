# Portal Copy: Claude Chat

## Short Description

Learn when to use Claude Chat, why context matters, how to turn vague requests into useful specifications, and how to work with files, projects, memory, connectors, skills, artifacts, usage limits, and output review.

## Long Description

This module prepares Sandvik users to use Claude Chat as a practical work partner. It starts with when Chat is the right product, then teaches intentional context, framing instructions, practical specification, conditional logic, agentic AI, files, projects, memory, connectors, skills, artifacts, five-hour and weekly usage limits, monthly spending-limit approval, output review, and when another Claude product is a better fit.

## Completion Rule

Users must pass the scored quiz with at least 80%. Retakes are unlimited.

## Estimated Time

35-45 minutes.

## Audience

Required for users ordering Claude Chat.

## Prerequisites

None.
