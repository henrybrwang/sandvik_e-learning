# Claude Enterprise is now available at Sandvik

---

**Claude Enterprise is live at Sandvik as of today.** To meet growing business demand for agentic AI and coding tools, you can now request access and start using it.

Claude Enterprise is a Sandvik-approved AI assistant for writing, research, analysis, and coding. It **complements** GitHub Copilot and Microsoft 365 Copilot, giving developers and advanced users access to an approved and governed AI platform for productivity, code generation, and desktop automation.

## Who is this for?

Claude Enterprise is primarily intended for **developers and heavy users** who need more advanced capabilities than standard AI tools, especially for coding, automation, and complex analysis. It complements existing tools like GitHub Copilot and Microsoft 365 Copilot, but is designed for more demanding use cases such as:

- Working with larger context and/or complex logic
- Agentic coding workflows
- Advanced debugging and scripting
- Scheduled task
- Design work

## Pick the tools you need

**One license covers all four tools at the same base cost**, no matter how many you choose. On the order form, select the ones you want:

| Tool | What it does | Notes |
| --- | --- | --- |
| **Claude Chat** | Ask questions, analyze documents, draft text, and research. | Web, desktop, and mobile. |
| **Claude Cowork** | Desktop agent that works with files such as spreadsheets and documents. | More complex tasks with larger context. |
| **Claude Code** | Coding assistant that runs in your terminal and helps write and debug code. | For developers and technical builders. |
| **Claude Design** | Visual design agent that creates and refines designs, layouts, and graphics through chat. | For visual design work. |

## Before you start: one short module per tool

We **highly recommend** completing the short learning module for **each tool you order**. Each module is completed separately, ends with a scored quiz, and takes roughly 20 to 45 minutes. It explains what the tool is, when to use it (and when another tool fits better), how to work safely within Sandvik policy, and how to manage usage and cost. We recommend finishing the module before you start using the tool.

## Pricing and cost model

Claude Enterprise is **consumption-based**, not just a fixed license. (This differs from Microsoft Copilot and the Microsoft Copilot Add-on License, where usage is included in the license.)

- **350 SEK per user/month** (base fee)
- **Usage costs are added on top**, depending on how much the service is used
- **Full cost is charged to your cost center with no markup**
- Users can request a **higher monthly usage/spending limit** through the [usage request form](https://serviceportal.sandvik.com/esc?id=sc_cat_item&sys_id=9a3ac9712b70cf505826f23cf291bfe1). A higher limit requires **approval from your cost approver**.
- Your monthly spending limit should be **visible in your Claude account**.

## How to get access

Ordering is **open now**, and licenses are being provisioned. To get started:

1. Open the order form and **select the tools you need**.
2. **Your request is reviewed and approved.**
3. Your license is provisioned and the cost is assigned to your cost center.
4. Before you start, complete the short module and quiz for each tool. This is highly recommended.
