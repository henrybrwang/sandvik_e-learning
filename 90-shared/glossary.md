# Glossary

| Term | Meaning |
| --- | --- |
| AI assistant | A system that responds to user instructions, drafts content, reasons over context, or uses approved tools. |
| Artifact | A substantial standalone output from Claude, such as a document, diagram, web page, or interactive component. |
| Claude Chat | The conversational Claude experience for asking questions, drafting, analyzing, summarizing, and iterating turn by turn. |
| Claude Cowork | A Claude Desktop mode for delegating multi-step work across files, browser, desktop apps, connectors, and tools. |
| Claude Code | An agentic coding system that can read a codebase, edit files, run commands, execute tests, and support development workflows. |
| Claude Design | A Claude product for creating visual work such as prototypes, slides, one-pagers, design directions, and shareable visual concepts. |
| Connector | An integration that lets Claude retrieve context or take actions in an approved external service. |
| Context | Information Claude can use in a conversation, such as messages, uploaded files, project knowledge, or connector results. |
| Data classification | Sandvik's internal label for how sensitive or restricted a piece of information is. |
| Hallucination | An output that sounds plausible but is incorrect, unsupported, outdated, or invented. |
| Human review | A person checks Claude's output before relying on it, sharing it, or using it for a decision. |
| MCP | Model Context Protocol, a standard for connecting AI systems to tools and data sources. |
| Memory | Claude's ability, when enabled, to use remembered context from prior conversations or projects. Availability and behavior may depend on plan and admin settings. |
| Plugin | A packaged set of Claude capabilities such as skills, connectors, and workflow instructions. |
| Prompt | The user's instruction to Claude, including goal, context, constraints, and requested output. |
| Prompt injection | Malicious or irrelevant instructions embedded in content that try to override user, company, or system instructions. |
| Project | A focused Claude workspace with its own instructions, knowledge, and chat context. |
| Sensitive information | Information that Sandvik classifies as confidential, personal, regulated, secret, export-controlled, or otherwise restricted. |
| Tool call | An action Claude takes through an approved tool, connector, browser, command line, or app. |
| Verification | Checking Claude's output against reliable sources, original documents, tests, or human expertise. |
