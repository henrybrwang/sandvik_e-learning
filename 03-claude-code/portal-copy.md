# Portal Copy: Claude Code

## Short Description

Learn how to use Claude Code with clear intent, safe experimentation boundaries, specifications, repository access, tests, Git workflow, and review loops.

## Long Description

This module prepares Sandvik developers, technical builders, and approved non-developers to use Claude Code responsibly across desktop, terminal, and IDE workflows. It covers when simple personal apps and prototype work are acceptable, when normal engineering procedure is required, how to use plan mode and repository instructions, how to protect secrets and production data, how to treat AI-written tests, and how to use review loops and approved deployment routes before shared or production-bound code is released.

## Completion Rule

Users must pass the scored quiz with at least 80%. Retakes are unlimited.

## Estimated Time

35-45 minutes.

## Audience

Required for users ordering Claude Code.

## Prerequisites

Developer, technical-builder, or approved exploratory role approved by Sandvik. Specific repository access and deployment must follow Sandvik policy.
