# Rollout Plan

## Phase 1: Content Foundation

- Create the folder structure and module templates.
- Draft shared policy placeholders, glossary, prompt patterns, and quiz schema.
- Build the source register from official Claude and Anthropic sources.
- Confirm the Sandvik ordering portal completion model.

## Phase 2: Module Drafting

Draft modules in this order:

1. Claude Chat
2. Claude Cowork
3. Claude Code
4. Claude Design

Claude Chat comes first because it establishes the general responsible-use baseline. The other modules can reuse its language for verification, sensitive data boundaries, and output review.

## Phase 3: Review

Route each module through the review checklist:

- Product accuracy
- IT Security
- Data Protection
- Legal
- Brand
- Portal/LMS implementation

Record review outcomes in each module's `review-notes.md`.

## Phase 4: Pilot

Pilot with a small group that includes:

- General business users
- Managers or assistants who work with documents and presentations
- Developers or technical contributors
- Users from more than one country or function

Suggested pilot measures:

- Completion time per module
- Quiz pass rate on first attempt
- Questions users found unclear
- Policy areas users found confusing
- Portal friction or tracking issues

## Phase 5: Publish

- Freeze the approved Markdown source.
- Export to the selected portal/LMS format.
- Upload quiz banks and completion rules.
- Verify reporting and completion status.
- Publish one module at a time if the portal supports staged release.

## Phase 6: Maintain

- Recheck official Claude and Anthropic sources quarterly.
- Review Sandvik policy placeholders after each internal policy update.
- Update quiz questions when product behavior or Sandvik rules change.
- Keep a changelog in each module's review notes.
